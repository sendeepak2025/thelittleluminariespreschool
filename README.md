# Little Luminaries Preschool Website

Static preschool website focused on parent trust, child growth, fast loading, and search-friendly structure.

## Edit Before Publishing

- Replace `littleluminaries.example` with the real domain in `index.html`, `robots.txt`, and `sitemap.xml`.
- Replace the phone, email, address, city, state, and postal code.
- Add real school photos when available.
- Submit the live sitemap in Google Search Console.

## Files

- `index.html` - main website page with SEO metadata and JSON-LD structured data.
- `styles.css` - responsive design.
- `script.js` - mobile menu and tour form message.
- `robots.txt` - crawl instructions.
- `sitemap.xml` - sitemap for search engines.
- `assets/little-luminaries-logo.png` - school logo used in the header and structured data.
- `assets/gallery-*.jpeg` - real Little Luminaries gallery and hero carousel photos.
